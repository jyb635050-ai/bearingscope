# 数据连接器与来源接入

本文说明 BearingScope 如何从 V1 样例模式扩展到真实来源。核心约束是：只访问公开或已授权的数据，遵守来源条款和访问频率，不绕过登录、验证码、付费墙、反爬机制或平台权限。

## 1. 数据流

```text
来源发现 → SourceAdapter 拉取 → 规范化 → 去重/关联 → 来源评级 → 人工或规则审核 → API/界面
```

每个适配器负责自身的认证、分页游标、速率限制、原始字段映射与健康状态；公共管线负责统一模型、时间和语言标准化、去重、来源优先级及可见性。

V1 的 `SampleSourceAdapter` 只读取本地样例数据。`BEARINGSCOPE_DATA_MODE=sample` 时不得发起外网请求。

建议的适配器合同：

```ts
interface SourceAdapter {
  readonly id: string;
  readonly sourceType: 'official' | 'rss' | 'news' | 'wechat' | 'journal' | 'regulator';
  fetchPage(input: { cursor?: string; since?: string; signal?: AbortSignal }): Promise<{
    items: unknown[];
    nextCursor?: string;
  }>;
  normalize(raw: unknown): ContentItem | null;
  health(): Promise<{ status: 'ok' | 'degraded' | 'down'; checkedAt: string; detail?: string }>;
}
```

真实实现应使用项目中的正式类型，不重复定义平行模型。

## 3. 微信公众号合规流程

微信公众号是一级来源，但“一级”代表来源接近事实，不代表可以任意采集全文。

### 允许的接入路径

1. **自有或获授权账号**：通过微信公众平台授予的官方能力获取许可范围内的数据。
2. **持牌/合规商业服务商**：使用合同明确允许存储与展示的字段，并遵守留存期。
3. **人工公开 URL**：用户提交 `https://mp.weixin.qq.com/s/...` 公开文章链接，系统验证后建立待审核项。

### URL 导入

`POST /api/v1/imports/wechat` 只接受 HTTPS 且主机名精确匹配 `mp.weixin.qq.com` 的公开文章 URL。服务端必须防止开放重定向和 SSRF；V1 可仅校验并排队，不需要请求页面。

待审核记录包含：提交 URL、规范化 URL、提交时间、可选品牌提示和状态。审核或授权导入后只保存标题、封面 URL、必要摘要、公众号显示名称、发布时间、公开原文链接、抓取/录入时间和授权依据。全文存储必须另有明确授权。

### 公众号名录

- 记录公众号显示名称、认证状态、品牌和地区映射、核验日期与核验依据。
- 不根据品牌名自动推断微信号，不在未核验时标注“官方”。
- 同一品牌可有集团、地区、业务线等多个认证账号；列表中保留其实际显示名称。
- 认证或品牌归属变化时停止自动发布，进入复核。

## 4. 规范化、去重和优先级

### 稳定标识

1. 新闻、微信和官网内容优先使用规范化 URL：移除跟踪参数与片段，统一主机名大小写，保留影响内容定位的参数。
2. 论文优先使用小写、去 URL 前缀的 DOI。
3. 无稳定标识时，生成“标准化标题 + 发布日期窗口 + 来源/品牌”的指纹。

同一事件的不同报道不应全部删除：保留官方或监管记录为主条目，把媒体和地区报道作为关联来源。完全重复时来源优先级为监管/交易所、企业官方或认证公众号、学术注册机构、通讯社/专业媒体、聚合来源。

### 时间与语言

- 内部时间使用 ISO 8601 UTC；显示时按用户区域格式化。
- `publishedAt` 与 `collectedAt` 分开保存，不能用抓取时间替代发布时间。
- 保留 `originalLanguage` 和原始标题；翻译作为独立字段并标出生成方式。
- 品牌别名用于检索和关联，例如 `JTEKT`/`Koyo`、`C&U`/`人本`、`ZWZ`/`瓦轴`，但不改写来源原文。

## 5. 连接器运行要求

- 每个域名设置明确的超时、并发数、速率和指数退避；尊重 `Retry-After` 与来源条款。
- 游标和最后成功时间可恢复；单个来源失败不能阻断整个聚合流程。
- 保存健康状态、最近成功/失败时间、返回数量和错误类别，不在日志中记录 API 密钥或全文。
- 对 HTML/RSS 结构变化使用契约测试和小规模夹具；解析失败时降级为待审核，不发布不完整事实。
- 原文删除、权限撤回或许可到期后，停止展示受限字段并保留最小审计记录。

## 6. 从样例模式升级

1. 在来源名录登记并人工验证域名、语言、条款、品牌映射与访问方式。
2. 为单一来源实现 `SourceAdapter`，先用保存的合法响应夹具测试，不直接扩大抓取范围。
3. 增加规范化、分页、限速、错误和去重测试。
4. 在隔离环境启用连接器，抽样核对原文、标题、发布时间、品牌和语言。
5. 通过合规审核后按来源逐个启用，并保留快速停用开关。
6. 监控错误率、延迟、重复率和人工审核退回率，再决定是否提高频率。

接入任何新闻或微信商业服务前，都应重新确认其当前条款、展示权、缓存期限与再分发限制；这些条件可能随服务版本变化。
